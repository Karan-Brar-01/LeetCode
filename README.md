# LeetCode Practice

A public collection of algorithm and SQL practice submissions, synchronized through LeetSync. The repository contains C++, Python, and SQL solutions alongside problem-specific READMEs.

This is practice history, not an application or a count of every problem solved on the author's LeetCode account. Submission runtime/memory figures in commit messages describe individual judge runs and are not comparable application benchmarks.

Browse a problem directory to read its statement and solution. Run solutions in the corresponding problem's judge/harness; there is no repository-wide build or automated test suite. No new submissions or history changes were made during the portfolio documentation review.
